Drop character pictures here to use them as the bot's Discord avatar.

Naming: <voice-id>.png (exact Fish Audio voice id) or <slugified-title>.png
(lowercase, spaces/punctuation -> underscores, e.g. 'Darth Vader' -> darth_vader.png).
A file named _default.png is used whenever there's no specific character
(random-voice mode, or the plain default voice) — save the bot's normal
profile picture here so it can revert to it.

Files the bot auto-downloads via Google Image search land here too, named
by the slugified title — replace one any time if the auto-pick is wrong.
